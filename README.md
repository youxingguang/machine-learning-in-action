机器学习实战笔记

一、 经典算法

监督学习使用带标注的数据集；无监督学习不需要使用带标注的数据集。

1. 线性回归 (Linear Regression)
   ```
   用途：回归预测
   学习范式：监督学习
   特点：简单、可解释型强，计算快。
   局限性: 只能建模线性关系，易欠拟合（对数据的特征捕获性差）
   ```
   

   
2. 逻辑回归 (Logistic Regression)
   ```
   用途：分类（二分类）
   学习范式：监督学习
   特点：概率输出，易解释
   局限性: 只能处理线性可分，对于复杂非线性关系无法准确划分
   ```

   
3. K近邻 (KNN)
   ```
   用途：分类/回归
   学习范式：监督学习
   特点：无需训练，简单直观
   局限性: 计算量大，对噪声敏感
   ```
    
4. 决策树 (Decision Tree)
   ```
   用途：分类/回归
   学习范式：监督学习
   特点：可解释强、可处理非线性
   局限性: 易过拟合
   ```
5. 随机森林 (Random Forest)
   ```
   用途：分类/回归
   学习范式：监督学习
   特点：抗过拟合，鲁棒性强
   局限性: 可解释下降
   ```
6. 梯度提升树 (GBDT)
   ```
   用途：分类/回归
   学习范式：监督学习
   特点：高精度、工业常用
   局限性: 训练慢、参数多
   ```
7. 支持向量机 (SVM)
    ```
   用途：分类/回归
   学习范式：监督学习
   特点：高维有效、理论完备
   局限性: 大数据下计算慢
   ```
    核方法
8. 朴素贝叶斯 (Naive Bayes)
    ```
   用途：分类
   学习范式：监督学习
   特点：简单高效，文本分类强
   局限性: 独立性假设过强
   ```
9. K均值 (K-Means)
    ```
   用途：聚类
   学习范式：无监督学习
   特点：快速，易实现
   局限性: 需要指定k,易陷入局部最优
   ```
10. 主成分分析 (PCA)
   ```
   用途：降维
   学习范式：无监督学习
   特点：去相关、降噪
   局限性: 只能线性降维
   ```
11. Apriori
   ```
   用途：关联规则挖掘
   学习范式：无监督学习
   特点：可解释规则
   局限性: 计算负责度高
   ```
12. EM 算法
   ```
   用途：参数估计
   学习范式：无监督/半监督学习
   特点：处理隐变量问题
   局限性: 易陷入局部最优
   ```
